### What's New in v1.0.0
- Full TeamSpeak 3 protocol client for Android (Modern Jetpack Compose Material 3 UI).
- Automatic audio routing: dynamic support for wired 3.5mm/Type-C headsets and Bluetooth headsets/hands-free devices (SCO/BLE).
- Active connection banner on the main screen with one-tap return to the current server.
- Smart Back button navigation (dialogs, chat, channel tree, exit/minimize dialog).
- Direct links to Near Corporation Telegram and GitHub in the About screen.
- Voice Activity Detection (VAD) and Push-to-Talk (PTT) with hardware key support.
- Channel chat, private messaging, file browser, and server management.
